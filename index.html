# origin story

I'm a Computer Science student who fell down the cybersecurity rabbit hole the way most of us do — one pkg install at a time. What started as installing random tools in Termux out of curiosity turned into a genuine obsession with red teaming and penetration testing: understanding how systems break so I can help defend them properly.

# what I run

School of Sec is the notebook I wish existed when I started — clear, no-fluff install guides for the tools that actually matter, built for people learning security from their phone before they ever touch a full pentest lab.
